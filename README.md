# Tarik Rahman — Academic CV Website

A static, responsive personal CV website for GitHub Pages. It uses plain HTML and CSS, with no build tools or external libraries.

## Preview locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a GitHub repository (for a personal site, name it `YOUR-USERNAME.github.io`).
2. Add `index.html`, `Tarik_Rahman_CV.pdf`, and this `README.md` to the repository root.
3. Push the files to the repository's `main` branch.
4. In the repository, open **Settings → Pages** and select **Deploy from a branch**, then choose `main` and `/ (root)`.
5. Visit the Pages URL shown in that settings panel.

The PDF download button points to `Tarik_Rahman_CV.pdf`. Replace that PDF whenever you update your CV. Update the LinkedIn link or contact details in `index.html` if needed.

## Customize

Edit the content and styles in `index.html`. The page is designed to work on desktop and mobile screens.
